## 🔧 聚合规则

### CRUD合并
同一模块的增删改查任务自动合并：
```
ID号取数-新增-后端 + ID号取数-编辑-后端 + ID号取数-列表-后端 + ID号取数-导入导出-后端
→ ID号取数（新增/编辑/列表/导入导出，后端，4项）
```

### 前缀合并
共享相同首段前缀的3+条任务自动合并：
```
ERP需求梳理-物流商资料 + ERP需求梳理-店铺管理 + ERP需求梳理-平台管理
→ ERP需求梳理相关开发（3项）
```

### Phase合并
同Phase阶段的任务自动合并：
```
沃尔玛爬虫Phase 2的5条任务
→ 沃尔玛商品库存爬虫开发（Phase 2）相关开发（5项）
```

### 单条保留
无法匹配以上模式的独立任务原样保留。

## 📋 字段说明

### 项目分组
- 【业财一体化】— 主项目
- 【TK数据看板项目】— TK相关
- 【RPA】— RPA开发与维护
- 【学习提升】— 学习培训
- 【其他工作】— 日常运维、会议、文档等

### 进度表示
| 状态 | 格式 |
|------|------|
| 已完成 | `- 完成` |
| 开发中 | `- 开发阶段` |
| 设计中 | `- 设计阶段` |
| 待处理 | 不显示状态 |

### 优先级标记
只有"紧急"和"高"优先级才显示：
- `【紧急】` — 紧急任务
- `【高】` — 高优先级任务
