# Colloquial Phrases Library

Phrases categorized by function. Sprinkle naturally - don't overuse any single phrase.

## Transitions (话题转换)

| Phrase | Usage |
|--------|-------|
| 对了，忘了说一个重要的事... | Add forgotten important point |
| 说到这里，突然想起... | Digress into related topic |
| 等等，这里有个细节要注意... | Interrupt self for caveat |
| 跑题了，拉回来... | Return from digression |
| 不过话说回来... | Counter-argument pivot |
| 换个角度看... | Offer alternative perspective |
| 说白了就是... | Simplify complex concept |

## Judgment & Assessment (判断评价)

| Phrase | Usage |
|--------|-------|
| 说实话... | Honest assessment |
| 其实吧... | Revealing hidden truth |
| 仔细想想... | Prompt deeper thinking |
| 按我的经验... | Personal experience anchor |
| 用下来的感觉是... | After practical use conclusion |
| 简单说就是... | Summarize in plain language |
| 不瞒你说... | Confide to reader |

## Self-Deprecation (自嘲拉近距离)

| Phrase | Usage |
|--------|-------|
| 刚开始我也是这么想的，后来发现... | Admit past mistake |
| 踩过坑才知道... | Lesson from failure |
| 这个是我吃了几次亏才明白的... | Painful learning experience |
| 说来惭愧... | Admit embarrassment |
| 别笑，我当年真的这么干过... | Share foolish past action |

## Emotion & Surprise (情绪表达)

| Phrase | Usage |
|--------|-------|
| 这时候问题来了... | Build tension before reveal |
| 你可能会问... | Preempt reader question |
| 怎么解决？ | Problem-solution pivot |
| 有意思的是... | Highlight unexpected finding |
| 离谱的是... | Express disbelief |

## Closeness (拉近读者距离)

| Phrase | Usage |
|--------|-------|
| 你想啊... | Engage reader reasoning |
| 你品品... | Ask reader to savor insight |
| 咱们举个例子... | Invite into example |
| 咱们来看看... | Invite into demonstration |
| 别急，先看看... | Slow down for explanation |

## Catchphrases (标志性口头禅)

| Phrase | Context |
|--------|---------|
| 不过要泼盆冷水 | Strategy series: before honest limitation assessment |
| 先写到这 | End of article, casual closing |
| 跑起来看看效果 | Before showing backtest results |
| 话不多，但都是实战踩坑总结出来的 | After experience section |
| 有问题欢迎留言交流 | Universal article closing |

## Tone Modifiers (语气词)

Light sprinkles for warmth, not in every sentence:

- 其实 / 说真的 / 说白了
- 了嘛 / 嘛 / 啊 (sentence-end particles)
- 吧 / 呢 (softening particles)

## Usage Rules

1. Each phrase used max ONCE per article
2. Natural placement - never force a phrase in
3. Match the section mood: self-deprecation in experience sections, surprise in results sections
4. Catchphrases are series-specific - don't use "泼盆冷水" in indicator series
