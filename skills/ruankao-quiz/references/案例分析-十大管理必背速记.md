# 案例分析必背清单

> 基于2015-2025真题统计 + 第四版教材三色笔记精校。案例分析3道题：1道计算（25分）+ 2道双拼理论（50分）。
> 加粗项为教材原文关键术语，必须精确记忆。

## 第一优先：每个领域的"过程名称"（最常考）

| 知识领域 | 过程数 | 必背内容 |
|---------|--------|---------|
| 整合管理 | 7个 | **制定项目章程**、**制定项目管理计划**、**指导与管理项目工作**、**管理项目知识**、**监控项目工作**、**实施整体变更控制**、**结束项目或阶段** |
| 范围管理 | 6个 | **规划范围管理**、**收集需求**、**定义范围**、**创建WBS**、**确认范围**、**控制范围** |
| 进度管理 | 6个 | **规划进度管理**、**定义活动**、**排列活动顺序**、**估算活动持续时间**、**制定进度计划**、**控制进度** |
| 成本管理 | 4个 | **规划成本管理**、**估算成本**、**制定预算**、**控制成本** |
| 质量管理 | 3个 | **规划质量管理**、**管理质量**、**控制质量** |
| 资源管理 | 6个 | **规划资源管理**、**估算活动资源**、**获取资源**、**建设团队**、**管理团队**、**控制资源** |
| 沟通管理 | 3个 | **规划沟通管理**、**管理沟通**、**监督沟通** |
| 风险管理 | 7个 | **规划风险管理**、**识别风险**、**实施定性风险分析**、**实施定量风险分析**、**规划风险应对**、**实施风险应对**、**监督风险** |

## 第三优先：绩效域与采购合同（2023后考频显著上升）

考法：**默写某个绩效域的预期目标**、写出绩效检查指标、结合案例判断绩效域问题

### 八大绩效域预期目标

| 绩效域 | 预期目标（教材原文） | 真题年份 |
|--------|-------------------|---------|
| 干系人绩效域 | ①建立高效的工作关系 ②干系人**认同**项目目标 ③支持项目的干系人**提高了满意度并从中收益**；反对项目的干系人**没有对项目产生负面影响** | 2023下4、2024下1 |
| 团队绩效域 | ①**共享责任** ②**建立**高绩效团队 ③所有团队成员都展现出相应的**领导力和人际关系技能** | 2025上1 |
| 开发方法和生命周期绩效域 | ①开发方法与项目**可交付物**相符合 ②将项目交付与干系人价值**紧密联系** ③项目生命周期由促进交付节奏的项目阶段和产生项目交付物所需的开发方法组成 | 2024下1 |
| 规划绩效域 | ①项目以**有条理、协调一致**的方式推进 ②应用**系统的方法**交付项目成果 ③对演变情况进行详细说明 ④规划投入的时间成本是适当的 ⑤规划的内容对管理干系人的需求而言是充分的 ⑥可以根据新出现的和不断变化的需求进行调整 | |
| 工作绩效域 | ①**高效且有效**的项目绩效 ②适合项目和环境的项目过程 ③干系人适当的**沟通和参与** ④对实物资源进行了有效管理 ⑤对采购进行了有效管理 ⑥有效处理了变更 ⑦通过持续学习和过程改进**提高了团队能力** | |
| 交付绩效域 | ①项目有助于实现**业务目标和战略** ②项目实现了**预期成果** ③在预定时间内实现了**项目收益** ④项目团队对需求有清晰地理解 ⑤干系人**接受**项目可交付物和成果，并对其满意 | 2023下3 |
| 度量绩效域 | ①对项目状况**充分理解** ②数据充分，可**支持决策** ③**及时采取行动**，确保项目最佳绩效 ④能够基于**预测和评估**作出决策，实现目标并**产生价值** | 2024上1 |
| 不确定性绩效域 | ①了解项目的运行环境（技术、社会、政治、市场和经济环境） ②**积极识别、分析和应对**不确定性 ③了解项目中多个因素之间的**相互依赖关系** ④能够对威胁和机会进行**预测**，了解问题的后果 ⑤**最小化**不确定性对项目交付的负面影响 ⑥能够利用机会**改进**项目的绩效和成果 ⑦有效利用**成本和进度储备**，与项目目标保持一致 | |

**记忆口诀（教材原文）：** 干系人-别理先参加(监)；团队-文化领导绩效；开发方法-节奏选择协调；规划-有组织、系统交付、演变说明、成本适当、内容充分、调整需求

## 第四优先：万能答题套路

### "找问题"题万能框架（按"人机料法环"）

- 人：人员配置不合理、缺乏经验、职责不清
- 机：工具/技术不合适、缺乏自动化手段
- 料：需求文档不完整、数据质量差
- 法：流程不规范、未按计划执行、缺乏评审
- 环：组织环境不支持、缺乏高层支持

### "改进措施"万能框架

1. 完善XX管理计划，明确流程和标准
2. 加强XX过程的执行，确保按计划进行
