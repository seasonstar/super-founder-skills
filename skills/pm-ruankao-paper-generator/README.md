# 软考高项论文生成器（pm-ruankao-paper-generator）

软考高级项目经理考试（信息系统项目管理师）论文自动生成技能，覆盖十大管理领域和八大绩效域。

> **默认场景**：本技能为用户（跨境电商企业 IT 总监）量身设计，所有模板与示例默认基于"跨境电商企业内部数字化项目"场景。
>
> **默认论文项目**：`XX 跨境电商集团业财一体化建设期项目`（**单一项目**，预算 1300 万、工期 24 月、单一项目章程）。项目下分两条业务条线：
> - ① **业务系统条线**（核心是供应链一体化）—— 业务系统组承载，自研 ERP1.0，覆盖产品/采购/仓库/物流/销售/计划/财务/统计/首页/运营工具/工具/系统等 12 个主模块、28 个业务版块、约 91 个子功能
> - ② **财务集成条线** —— 数据效能组承载，含金蝶云星空集成模块（OA→应收单、积加→应收单）、利润报表模块、发票智能识别模块等
>
> **节奏**：分阶段交付（前期财务集成模块小步快跑、中期 ERP 主线滚动迭代、后期联调上线），所有交付物都属于**同一项目章程**下的范围基准——**论文写单一项目，不写项目集**。
>
> **真实技术栈**：Spring Boot 2.7 / MyBatis-Plus / MySQL 8 / Redis / Vue 3 / Element Plus / ECharts / Python + FastAPI + Pandas / Doris + DolphinScheduler / Nginx / Docker / 影刀 RPA / Playwright / 积加 ERP / 马帮 ERP / 金蝶云星空 / 钉钉 / 飞书 / GitLab。
>
> **禁止默认引入**：甲乙方/中标承接、麒麟OS/达梦数据库/东方通中间件、智慧水务/数字政务、UiPath/Kafka/ClickHouse/Airflow/Apache Superset/RabbitMQ、"IT 经理（兼 IT 总监）"等重复表述、RACI 作为主图表（软考高项极少考）、"双轮驱动 / 自下而上+自上而下 / 先支撑后引领"等项目集层级方法论叙事、把项目写成多个并列子项目的"项目集"形态。

## 功能概览

| 能力 | 说明 |
|------|------|
| 十大管理论文 | 整合/范围/进度/成本/质量/资源/沟通/风险/采购/干系人，按过程组四段式展开 |
| 八大绩效域论文 | 干系人/团队/规划/度量/开发方法和生命周期/工作/交付/不确定性，按绩效要点式展开 |
| 图表生成 | 10类 mermaid 图表模板（甘特图、S曲线、网络图、WBS、权力利益方格等） |
| 融合写作 | 支持"绩效域 × 十大管理 × 量化指标"三维融合论文 |
| 质量验证 | 6项强制检查：字数、格式、内容、逻辑、主题一致性、特殊要求 |

- "请按照软考标准写一篇论文"
- "给我一个软考论文模板"
- "优化我写的软考论文"

## 论文生成流程

```
步骤一：信息确认与主题锁定
  ├── 十大管理 → 确认过程组（4-6个过程）
  └── 绩效域 → 确认绩效要点数量，读取 performance-domains.md

步骤二：背景段落生成（500-600字）
步骤三：过渡段落生成（≤300字）

步骤四：正文段落生成
  ├── 4A 十大管理 → 过程组四段式（定义→场景→工具→效果）
  └── 4B 绩效域 → 绩效要点展开 + 预期目标检查 + 协同关系

步骤五：收尾段落生成（≤300字）
步骤六：强制验证与质量检查（6项检查全部通过后才输出）
```

## 图表支持

备考资料支持两种图表形式：

| 形式 | 适用场景 | 考试时 |
|------|---------|--------|
| Markdown 表格 | WBS表、挣值表、风险登记册、干系人矩阵 | 用制表符手工绘制 |
| Mermaid 图表 | 甘特图、S曲线、网络图、流程图、协同关系图 | 用机考画板手工还原 |

支持 10 类 mermaid 图表：甘特图、S曲线、网络图/PERT、WBS分解树、权力利益方格、绩效域协同图、风险应对流程图、业务流转图、生命周期阶段图、度量仪表盘结构图。
